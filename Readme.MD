# MLOps Lab 5 – Model Training & MLflow Tracking

This project contains the code and notebook for training machine learning models and tracking experiments using **MLflow**.

---

## 🚀 Getting Started

Follow the steps below to set up your environment and run the notebook.

---

## 1. Create and Activate the Virtual Environment

### ▶️ Windows (PowerShell)
```powershell
python -m venv lab_5
lab_5\Scripts\Activate
```

#### 2. Install  dependencies.

```pip install -r requirements.txt
```

### 3. Run MLFlow.ipynb 
This will create the models 

### 4. Run MLFLOW UI
```mlflow ui --port 5001
```

Then open http://127.0.0.1:5001
